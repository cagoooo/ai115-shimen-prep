# 石門國小 115 年度 AI 素養爭霸賽教學實施計畫（備戰版）

> 適用對象：桃園市龍潭區石門國民小學兩位六年級學生與指導教師
>
> 文件定位：校內備戰與教學安排，不取代桃園市政府教育局或教育部正式公告。
>
> 查核日期：2026-09-14（民國 115 年）

## 一、目前最需要完成的行政事項

1. 由兩位六年級學生組成一隊，確認參加正式賽「國小魷魚組」。若學校是否屬偏鄉組有疑義，向桃園市承辦單位確認，不自行猜測。
2. 指定一位與學生同校編制內的指導教師。
3. 於 115/9/18（五）中午 12:00 前，由學校從「學校介面」完成推薦隊伍報名。桃園市公告的報名期間為 9/10（四）中午 12:00 至 9/18（五）中午 12:00。
4. 下載並固定使用 PAIA Desktop 3.3.5 與「魷來魷去對戰版」1.7.5；正式賽遊戲設定選擇「地圖：12」。
5. 追蹤桃園市官方公告的競賽場地、休息區、停車區與臨時調整。場地預計在協辦學校電腦教室，實際地點以公告為準。

## 二、學生學習目標

學生在市賽前應能做到：

- 能登入 PAIA、建立／開啟正式賽遊戲專案並確認版本與地圖。
- 能用自己的話解釋資料、模型、訓練與推論的差別。
- 能走完「觀察遊戲 → 蒐集資料 → 訓練監督式模型 → 測試 → 修正」的循環。
- 能在沒有老師逐步提醒的情況下，完成 `ml_play.py` 與模型檔的匯出和上傳前核對。
- 知道不能載入預存資料、模型或程式，不能使用硬編碼規則直接送出遊戲指令，也不能在比賽中使用外部網路服務。
- 兩位學生都能擔任資料觀察員與程式測試員，並且能口頭說明自己選擇模型版本的理由。

## 三、校內五段課程安排

| 日期 | 主題 | 學生任務 | 教師觀察證據 |
|---|---|---|---|
| 9/14–9/18 | 報名與環境 | 完成登入、安裝、版本／地圖核對；知道正式賽為監督式學習 | 每位學生可獨立開啟 PAIA 與遊戲專案 |
| 9/19–9/21 | 遊戲觀察 | 手動操作，記錄食物、垃圾、對手、座標、距離與角度等可觀察資訊 | 學生能描述一個情境與想讓 AI 做的行動 |
| 9/22–9/25 | 第一個模型 | 依教材建立蒐集與訓練流程，完成第一個可執行模型 | 有樣本、有訓練結果、有測試紀錄 |
| 9/26–9/28 | 穩定與比較 | 用不同情境測試，補足偏少的樣本；保留至少兩個候選版本 | 學生能指出每次只改動的一個因素 |
| 9/29–10/2 | 模擬賽 | 清空預存素材，限時 2 小時從零完成全流程與上傳核對 | 兩位學生都能完成交件，且通過合法性清單 |

每次課程建議 30–60 分鐘；最後一段至少安排一次完整的 2 小時計時。練習資料與模型只作為校內學習紀錄，不能直接帶入正式競賽當作預存素材。

## 四、兩人分工與輪替

### A：資料觀察員

- 描述目前畫面與可觀察特徵。
- 判斷樣本是否只集中在單一距離、方向或結果。
- 用紙筆記錄「看到什麼、做了什麼、結果如何」。
- 提醒隊友先理解資料，再決定是否補樣本。

### B：程式測試員

- 操作 PAIA 積木、訓練與測試模型。
- 檢查程式是否由模型推論控制行動。
- 保存測試結果、匯出 Python 檔與模型檔。
- 執行檔案名稱、格式、容量與上傳檢查。

每一回合後交換 A／B。老師只在規則、技術或安全問題上介入，不替學生決定每一步策略。

## 五、兩小時模擬賽建議節奏

這是校內訓練用配時，不是主辦單位另訂的官方分段：

| 時間 | 建議動作 |
|---|---|
| 00:00–00:10 | 讀題、核對地圖、分工與資料策略 |
| 00:10–00:35 | 蒐集第一批多樣樣本 |
| 00:35–01:05 | 訓練第一個可執行模型 |
| 01:05–01:35 | 用未看過的情境測試並記錄 |
| 01:35–01:50 | 補資料／重新訓練／比較候選版本 |
| 01:50–02:00 | 匯出、檢查、準備交件 |

上傳前由兩人逐項念出：`ml_play.py`、模型檔、總容量小於 20 MB、程式會載入模型、已通過 AI 線上檢測。

## 六、競賽日安排

桃園市實施計畫目前列出的國小組流程如下，實際時程可能調整：

- 08:00–08:40：選手報到。
- 08:50–09:00：規則說明及公布題目。
- 09:00–11:00：學生程式撰寫、訓練 AI 模型競賽。
- 11:00–12:00：作品上傳繳交，由工作人員確認。
- 12:50–13:00：隨機抽籤分組「對戰」表。
- 13:00–18:00：雙敗淘汰對戰；每場三戰二勝，分數高者勝，同分依規定延長。

學生須攜帶學生卡／桃樂卡；若沒有，依實施計畫由學校出具附照片的在學證明。會場提供電腦、隨身碟、紙筆等設備，其他資訊設備不得攜入；交通、午餐、陪同與請假由學校依校內規定安排。

## 七、合法性與交件檢核

### 必須通過

- 開發環境為 PAIA Desktop 3.3.5。
- 正式賽遊戲為魷來魷去對戰版 1.7.5、地圖 12。
- 正式賽採監督式學習。
- 兩小時內現場寫程式、蒐集資料、訓練與測試。
- Python 程式命名為 `ml_play.py`，另有自訂名稱的 `.pickle` 或 `.zip` 模型檔。
- 程式行動由模型推論結果控制，且通過 AI 線上檢測。
- 上傳檔案總和不超過 20 MB。

### 絕對不要

- 載入賽前準備好的資料、模型或程式。
- 以 `if/else` 等硬編碼規則直接對應題目答案並送出遊戲指令。
- 比賽時下載外部模型、資料集或使用第三方即時服務。
- 使用系統漏洞、未公告參數、共用硬碟或其他未授權方式取得優勢。
- 將額外資訊設備帶入競賽會場。
